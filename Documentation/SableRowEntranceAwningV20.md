# Sable Row entrance awning V20

Replaced V18's narrow flat canopy in the V19 scene with a sloping, weathered sheet-metal awning informed by the supplied ext_apartment_base.png. Width 1.64 m, projection 1.36 m, front drip edge z=2.77 m. Added raised seams, folded edges, wall flashing and triangular brackets. Existing tenant bell plate and five individual buttons retained. No character, navigation or runtime assets changed.

Saved incremental backup and final scene under ArtSource/Blender/SableRowDistrictV20. Ordered live Blender MCP modelling code is preserved in live_awning_operations.json. Day and noir entrance renders were visually inspected. The roof bounding box does not intersect any active front fire-escape component; see reviews/awning_checks.json. These are review renders, not regenerated full district masters or a runtime installation.

Historical distinction: audio intercom technology existed in the 1950s, as documented by [Aiphone](https://www.aiphone.com/about/). This establishes availability of the technology, not prevalence in an early-1950s American tenement. The existing simple tenant bell panel is retained rather than attributing a specific later intercom model to this building.
